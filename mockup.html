What changed vs current

  • Palette — replace raw ANSI named colors (Green/Yellow/Red/Cyan/Magenta) with catppuccin-mocha RGB. Borders, badges, footer chip all retuned. Falls back gracefully on truecolor terminals; 256-color terminals get nearest match.
  • Rounded borders — every popup, sidebar, and tile uses BorderType::Rounded (╭ ╮ ╰ ╯ instead of ┌ ┐ └ ┘).
  • Title bar — new top strip: ◆ cmux · sessions count · focus · cpu/mem (optional) · clock. Anchors identity at top.
  • Animated spinner — busy sessions' badge cycles braille frames ⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏ at ~4fps (matches the existing 250ms heartbeat). Idle / dormant / dead keep static glyphs.
  • Session sidebar enrichment — adds ⏱ age, ▤ tokens, ◐ ctx% from the claude status JSON we already parse. Two-line per session card.
  • Mode chip — solid background block with black text. Higher contrast than current dark-gray fill. Identical content, more presence.
  • Footer — keys color-keyed: cyan = chord letter, muted = description. Right-aligned: copy hint + version. kbd styling for modifier names.
  • Subtle backgrounds — focused session gets bg-active fill in sidebar; section dividers use 1-pixel border, not character runs.
  • Tile title overlay — title floats on the border (like ratatui already does); kept the focus dot in green.
  • Not in this pass: empty-state ascii art, popup logos, syntax-highlighted preview pane.

Things to adjust

  • Palette: catppuccin-mocha or pick another (gruvbox, tokyonight, rose-pine, nord, dracula).
  • Title bar contents — strip cpu/mem? add per-session token total? add cmux version?
  • Sidebar meta row — which fields matter most (age / tokens / ctx% / cost)?
  • Spinner glyph set — braille (shown), bouncing dot ⡀ ⠄ ⠂ ⠁, classic | / - \\, or none.
  • Rounded vs Thick (┏ ┓ ┗ ┛) vs Double (╔ ╗ ╚ ╝) borders.
  • Mode chip — solid block (shown) vs outlined vs underline-only.
